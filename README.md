# LUZACODE V1

Versão V1 do LUZACODE para aprender, escrever, testar e guardar projetos.

## Alterações desta versão
- Tema escuro completo, com contraste de texto em todas as áreas.
- Removidos os blocos estatísticos do final da página inicial.
- Tela cheia no editor e também no painel de Resultado, com botão **← Voltar** e suporte a Esc.
- Manual com explicações mais detalhadas: o que é, para que serve, como escrever, exemplo e resultado.
- 3 cursos: HTML do zero, CSS do zero e JavaScript do zero.
- Cada curso tem 18 exercícios: 6 Iniciante, 6 Intermédio e 6 Avançado.
- O progresso reinicia a barra a cada mudança de nível.
- Estado final **Concluído** após os 18 exercícios.
- Botão para reiniciar os cursos.
- Sistema de conquistas.
- Desafios separados por Fácil, Médio e Difícil.
- Desafio do Dia.
- Mantida a estrutura simples e o menu principal da versão base.
